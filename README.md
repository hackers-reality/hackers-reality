## 🧠 What I Build

I build **autonomous AI agents, developer tools, automation-heavy systems and full-stack products**.

I'm less interested in making another chatbot wrapper and more interested in the engineering that begins **after** the first model response: giving an agent context, memory, tools, permissions, workflows, parallel workers, verification loops and enough structure to keep going when a task gets large.

```text
context → reason → plan → delegate → use tools → execute → verify → self-correct → continue
```

A model matters. But the way you **prompt it, train its working context, orchestrate it, give it tools and force it to verify its own work** can matter just as much.

## 🤖 Flagship Project — FRIDAY

### [→ hackers-reality/friday](https://github.com/hackers-reality/friday)

**FRIDAY** is my open-source, Windows-native autonomous AI agent inspired by Iron Man's FRIDAY.

It goes considerably beyond chat: voice and live audio, screen awareness, desktop and browser automation, persistent memory, goals and productivity enforcement, communications, model routing, multi-agent delegation, parallel sub-agents, research workflows, scheduling, GitHub integration, self-modification, a sidecar network, dashboards and more.

The goal isn't to imitate a movie UI. It's to explore what happens when a personal AI can **observe, remember, reason, use tools and actually act**.

## 🧩 My Agent Engineering Philosophy

```text
                     ┌─────────────┐
                     │    MODEL    │
                     └──────┬──────┘
                            │
              ┌─────────────┼─────────────┐
              ↓             ↓             ↓
           CONTEXT         TOOLS       GUARDRAILS
              │             │             │
              └─────────────┼─────────────┘
                            ↓
                       ORCHESTRATION
                            ↓
                 ┌──────────┴──────────┐
                 ↓                     ↓
             EXECUTION          PARALLEL AGENTS
                 └──────────┬──────────┘
                            ↓
                       VERIFICATION
                            ↓
                      SELF-CORRECTION
                            ↓
                         CONTINUE
```

The fun part is not asking an AI to write one function.

The fun part is giving an agent a real engineering objective, enough context to understand the system, the ability to inspect its environment, delegate work when useful, test what it built, catch its own mistakes, repair them, and keep moving until the objective is actually complete.
